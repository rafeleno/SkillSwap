# SkillSwap

Сервис позволяет находить взаимно подходящие пары, отправлять заявки на обмен и вести список текущих/завершённых сессий.

## Быстрый старт

```bash
# Установка зависимостей
npm install

# Запуск в режиме разработки
npm start
```

## Создание нового компонента

```bash
npm run create
```

1. Выберите тип компонента:
   - **ui** - базовые элементы (кнопки, инпуты, селекторы)
   - **widgets** - составные компоненты (карточки, блоки)
   - **pages** - страницы приложения

2. Введите название компонента

3. Готово! Создастся папка с файлами:
   - `index.ts` - точка входа
   - `[название].tsx` - основной компонент
   - `styles.module.scss` - стили
   - `[название].types.ts` - типы

### Использование стилей

```tsx
import styles from './styles.module.scss'

<div className={styles.yourClass} />
```
